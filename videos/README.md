# Vidéos des leçons

Mettez ici une courte vidéo par leçon. L'application la joue automatiquement, **au ralenti et en boucle**.

## Noms des fichiers

Le nom doit être exactement celui-ci (sinon la vidéo n'apparaît pas) :

| Fichier | Leçon |
|---|---|
| `cast-on.mp4` | Monter les mailles |
| `knit.mp4` | Maille endroit |
| `garter.mp4` | Point mousse |
| `bind-off.mp4` | Rabattre les mailles |
| `weave-ends.mp4` | Cacher les bouts de fil |
| `purl.mp4` | Maille envers |
| `rib-2x2.mp4` | Côtes 2/2 |
| `new-ball.mp4` | Changer de pelote |
| `dropped.mp4` | Rattraper une maille tombée |
| `stockinette.mp4` | Jersey |
| `k2tog.mp4` | 2 mailles ensemble |
| `seaming.mp4` | Coudre deux bords |

## Conseils pour filmer

- **10 à 20 secondes**, un seul geste répété 2 ou 3 fois. Pas besoin de son.
- Filmez **par-dessus l'épaule**, comme si c'était elle qui tricotait (pas en face).
- Une laine **claire et épaisse**, des aiguilles qui contrastent avec la laine, et beaucoup de lumière.
- Téléphone tenu **à l'horizontale**, sans bouger (posé contre quelque chose).
- Gardez chaque fichier **sous 10 Mo** (sur la plupart des téléphones, une vidéo de 15 s en 720p fait déjà moins).

## Ajouter une vidéo sur GitHub

1. Ouvrez ce dossier `videos` sur github.com.
2. **Add file → Upload files**, déposez la vidéo (renommée comme dans le tableau).
3. **Commit changes**. Une minute plus tard, la vidéo est dans l'application de tous les téléphones.

On peut aussi ajouter une vidéo directement depuis le téléphone (bouton ⋯ en bas de chaque leçon) :
elle reste alors seulement sur ce téléphone.
